# Premium Companies Plugin - Режимы отображения

## Версия 2.1.0 - Новый Inline Mode для интеграции в формы! 🎉

Premium Companies Plugin теперь поддерживает **4 режима отображения** для разных сценариев использования.

---

## 📋 Доступные режимы

### 1. **Cards** (Карточки) - По умолчанию
**Когда использовать:** Отдельная секция на странице, лендинги, акцентированное отображение

**Характеристики:**
- ✅ Полноценные карточки с изображениями
- ✅ 3 колонки на десктопе (1→2→3)
- ✅ Большой uk-section с отступами
- ✅ Детальная информация о компаниях
- ✅ Контактная информация (телефон, сайт)
- ✅ Красивые hover-эффекты

**Внешний вид:**
```
┌─────────────────────────────────────────────────┐
│   Рекомендуемые премиум компании                │
├─────────────────────────────────────────────────┤
│  ┌────────┐  ┌────────┐  ┌────────┐            │
│  │ [IMG]  │  │ [IMG]  │  │ [IMG]  │            │
│  │ Title  │  │ Title  │  │ Title  │            │
│  │ Desc   │  │ Desc   │  │ Desc   │            │
│  │ Phone  │  │ Phone  │  │ Phone  │            │
│  │ [BTN]  │  │ [BTN]  │  │ [BTN]  │            │
│  └────────┘  └────────┘  └────────┘            │
└─────────────────────────────────────────────────┘
```

---

### 2. **List** (Список)
**Когда использовать:** Компактное отображение с сохранением деталей

**Характеристики:**
- ✅ Вертикальный список
- ✅ С изображениями
- ✅ Полная информация
- ✅ Экономия горизонтального пространства

---

### 3. **Compact** (Компактный)
**Когда использовать:** Ограниченное пространство, sidebar, виджеты

**Характеристики:**
- ✅ Минимальные отступы
- ✅ Опциональные изображения
- ✅ Без контактной информации
- ✅ Только название и кнопка

---

### 4. **Inline** (Встроенный) - ⭐ НОВЫЙ в v2.1.0
**Когда использовать:** **Интеграция прямо В форму добавления заказа**

**Характеристики:**
- ✅ **Ультра-компактный дизайн**
- ✅ **БЕЗ изображений** (экономия места)
- ✅ **БЕЗ больших отступов** (гармонично в форме)
- ✅ **2 колонки** на десктопе
- ✅ **Премиум звездочка** вместо бейджа
- ✅ **Минимальный padding** (12px)
- ✅ **Адаптивный** (1 колонка на мобильных)

**Внешний вид:**
```
┌─────────────────────────────────────────────────┐
│ ⭐ Рекомендуемые премиум компании               │
├───────────────────┬─────────────────────────────┤
│ ⭐ Ателье "Элегант│ ⭐ Пошив свадебных платьев  │
│ 🏠 Компания       │ 🏷️ Объявление производства  │
│         [Подробне]│              [Подробнее]    │
├───────────────────┼─────────────────────────────┤
│ Швейная мастерска │ Индивидуальный пошив       │
│ 🏠 Компания       │ 🏷️ Объявление производства  │
│         [Подробне]│              [Подробнее]    │

```

## 🔧 Как включить Inline Mode?

### Шаг 1: Настройки плагина
1. Откройте **Система → Плагины → Premium Companies**
2. Найдите секцию **"Display Settings"**
3. В поле **"Display Style"** выберите **"Inline (Form Integration)"**
4. Нажмите **"Сохранить"**

### Шаг 2: Интеграция в шаблон
Используйте код из файла `integration-inline-form-example.php`:

```php
<?php
// Импортируем плагины
PluginHelper::importPlugin('content');

// Создаем объект
$article = new stdClass();
$article->text = $app->input->get('description', '', 'raw');

// Триггерим событие
$dispatcher = Factory::getApplication()->getDispatcher();
$results = $dispatcher->triggerEvent('onContentBeforeDisplay', array(
    'com_djclassifieds.additem',
    &$article,
    &$params,
    0
));

// Выводим результаты (компактно!)
foreach ($results as $result) {
    echo $result;
}
?>
```

### Шаг 3: Проверка
Откройте форму добавления заказа - рекомендации будут отображаться компактно и гармонично!

## 💡 Рекомендации

### Используйте Inline Mode если:
- ✅ Интегрируете В форму добавления заказа
- ✅ Нужен ненавязчивый дизайн
- ✅ Ограничено пространство
- ✅ Важна скорость загрузки
- ✅ Целевая аудитория - мобильные устройства

### Используйте Cards Mode если:
- ✅ Отдельная секция на странице
- ✅ Нужен акцент на компаниях
- ✅ Важны визуальные детали
- ✅ Достаточно пространства
- ✅ Лендинг или промо-страница
