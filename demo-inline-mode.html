Что такое Inline Mode?

Inline Mode (Встроенный режим) - это компактный дизайн для гармоничного отображения рекомендаций прямо внутри формы добавления заказа. Карточки компактные, без больших отступов и изображений.

  • Отдельный блок от формы
  • Идеален для лендингов

Как включить Inline Mode?

  1. Откройте Система → Плагины → Premium Companies
  2. В разделе "Display Settings" найдите "Display Style"
  3. Выберите "Inline (Form Integration)"
  4. Сохраните настройки
  5. Готово! Рекомендации будут отображаться компактно прямо в форме

Преимущества Inline Mode

  • 📱 Лучше для мобильных устройств - занимает меньше места
  • 🎨 Гармоничная интеграция - не выделяется из формы
  • ⚡ Быстрая загрузка - не загружает изображения
  • 👁️ Меньше отвлекает - пользователь фокусируется на форме
  • ✅ Больше конверсия - ненавязчивые рекомендации
