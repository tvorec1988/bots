🔧 Варианты позиций для интеграции

Позиция 1: После категории

Где: После выбора категории и полей

Преимущества:

  • ✅ Логично - после выбора категории
  • ✅ Компании сразу видны
  • ✅ Не мешают заполнению формы

После: categoryfields

Позиция 2: После описания

Где: После поля описания объявления

Преимущества:

  • 📝 После ввода описания
  • 🤖 AI может анализировать текст
  • 👍 Релевантные рекомендации

После: description

Позиция 3: Перед кнопками

Где: Перед кнопками Сохранить/Отмена

Преимущества:

  • 👁️ Последнее что видит пользователь
  • 💡 Финальная подсказка
  • 🎯 Перед отправкой формы

Перед: classifieds_buttons

💻 Код для вставки

1 Откройте файл шаблона (см. пути выше)

2 Найдите нужную позицию (рекомендуется после categoryfields)

3 Вставьте этот код:

<?php // ============================================================ // PREMIUM COMPANIES PLUGIN INTEGRATION // Shows recommended companies from J-Business Directory // ============================================================ use Joomla\CMS\Plugin\PluginHelper; use Joomla\CMS\Factory; // Import content plugins PluginHelper::importPlugin('content'); // Create article object for plugin $premiumArticle = new stdClass(); $premiumArticle->text = ''; $premiumArticle->cat_id = Factory::getApplication()->input->getInt('cat_id', 0); // Create empty params object $premiumParams = new \Joomla\Registry\Registry(); // Trigger onContentBeforeDisplay event $dispatcher = Factory::getApplication()->getDispatcher(); $premiumResults = $dispatcher->triggerEvent('onContentBeforeDisplay', array( 'com_djclassifieds.additem', &$premiumArticle, &$premiumParams, 0 )); // Output results from plugins if (!empty($premiumResults)) { foreach ($premiumResults as $result) { if (!empty($result)) { echo $result; } } } ?>

4 Сохраните файл

5 Настройте плагин (см. раздел ниже)

⚙️ Настройка плагина после интеграции

1. Включите плагин

  • Расширения → Плагины
  • Найдите "Content - Premium Companies for DJ-Classifieds"
  • Убедитесь что статус = Включен

2. Укажите целевые страницы

В настройках плагина добавьте URL страницы добавления:

/index.php?option=com_djclassifieds&view=additem

Это критично! Без этого плагин не будет работать.

3. Рекомендуемые настройки для формы

Параметр Значение
Maximum Companies 5-7 (не перегружать форму)
Show All Companies Да
Match by Category Да
Display Style Compact (для формы)
Show Company Logo Да
